GitHub main is the source of truth. After validated software changes, run applicable host/script/ARM tests and strict firmware verification; retain the current field HEX/ELF, update README/current and root tracked-source SHA256 manifests, then normal commit/push origin/main and live ls-remote verification. No PR or force push. Do not generate ZIPs, archives, bundles, nested deliveries or package-verification prerequisites.

Preserve unique field evidence and historical engineering records/firmware. Inspect generated directories before removing ignored software build/test artifacts. Retain tracked test records and unique physical evidence; ignored raw software logs/final/repro outputs are rebuildable under the current cleanup policy. Never reset --hard, clean -fdx or overwrite field originals. Do not connect serial, flash or move hardware in an agent session. Software PASS is not physical validation.
